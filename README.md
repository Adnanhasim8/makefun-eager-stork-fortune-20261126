# makefun-eager-stork-fortune-20261126

Entry for the make.fun competition **Fortune Cookie Funnies for Engineers**
(`u-eager-stork-81-9647-fortune-cookie-funnies-for-866bde2a`).

`main.py` (Python 3.13 standard library only, no network at run time) writes a
single fortune cookie message for a software engineer — one line, at most 120
characters — to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

That writes the fortune to `/output/entry.txt`. To write elsewhere:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
# or
python3 main.py --out /tmp/out/entry.txt
```

## The fortune

> Yesterday you deleted one line of code. It was holding up production.
